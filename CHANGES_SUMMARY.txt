HOW IT WORKS:
================================================================================

AUTOMATIC INVENTORY DEDUCTION:
------------------------------
1. Cashier adds items to cart
2. Cashier completes payment
3. Order status changes from 'new' to 'paid'
4. Database trigger fires automatically
5. Inventory quantities deducted from branch stock
6. Frontend refreshes to show updated stock

OVERSELLING PREVENTION:
----------------------
1. Each item shows available stock quantity
2. When adding to cart, system checks:
   - Is it a recipe? → No limit (recipes are made on demand)
   - Is it regular item? → Check stock quantity
3. If cart quantity would exceed stock:
   - Show alert: "لا يمكن إضافة المزيد. الكمية المتاحة: X"
   - Prevent adding more items
4. Same validation when using +/- buttons in cart

TECHNICAL DETAILS:
================================================================================

DATABASE TRIGGER:
----------------
Name: trigger_deduct_inventory_on_payment
Type: AFTER UPDATE on orders table
Condition: When status changes to 'paid'
Action: Deducts quantities from inventory table

Function: deduct_inventory_on_payment()
- Loops through all order_items
- Updates inventory.quantity for each item
- Only processes items with item_id (not menu_items)
- Logs warning if inventory record missing

FRONTEND VALIDATION:
-------------------
Function: handleAddToCart(item)
- Checks if item is recipe (no validation)
- Gets current cart quantity for item
- Compares cart qty + 1 vs stock quantity
- Shows alert if would exceed stock
- Prevents adding if limit reached

Function: handleUpdateQuantity(itemId, newQuantity)
- Finds item in menu items list
- Checks if recipe (no validation)
- Compares new quantity vs stock quantity
- Shows alert if exceeds stock
- Prevents update if limit reached

Function: handlePayment() (updated)
- Creates order
- Processes payment
- Calls fetchData() to refresh stock
- Updates UI with new quantities

VERIFICATION QUERIES:
================================================================================

Check if trigger is installed:
-----------------------------
SELECT trigger_name 
FROM information_schema.triggers
WHERE trigger_name = 'trigger_deduct_inventory_on_payment';

Expected: 1 row returned


Check current stock levels:
--------------------------
SELECT 
  b.name_ar as branch,
  i.name_ar as item,
  inv.quantity as stock
FROM inventory inv
JOIN branches b ON b.id = inv.branch_id
JOIN items i ON i.id = inv.item_id
WHERE b.is_main_warehouse = false
ORDER BY b.name_ar, i.name_ar;


Check recent sales:
------------------
SELECT 
  o.order_number,
  o.paid_at,
  i.name_ar as item,
  oi.quantity as sold,
  inv.quantity as remaining
FROM orders o
JOIN order_items oi ON oi.order_id = o.id
JOIN items i ON i.id = oi.item_id
LEFT JOIN inventory inv ON inv.branch_id = o.branch_id AND inv.item_id = oi.item_id
WHERE o.status = 'paid'
ORDER BY o.paid_at DESC
LIMIT 10;
